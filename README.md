Sphinx documentation for the PyQt5 School Management System built in Lab 2.
Every module, class and function has a Sphinx-style docstring, and the HTML
site is generated automatically from them with `autodoc`.

## Project structure

```
Week3/
├── part1_oop.py          Object model: Person, Student, Instructor, Course, School
├── part3_pyqt.py         PyQt5 graphical interface (SchoolWindow)
├── part4_database.py     SQLite persistence layer (Database)
├── requirements.txt
└── docs/
    ├── conf.py           Sphinx configuration
    ├── index.rst         Documentation home page
    ├── modules.rst       Generated by sphinx-apidoc
    ├── part1_oop.rst
    ├── part3_pyqt.rst
    ├── part4_database.rst
    ├── Makefile
    ├── make.bat
    └── _build/html/      Generated website
```

## Generating the documentation

The documentation was created with the following steps:

1. `sphinx-quickstart` inside `docs/`, with project name, author, copyright and version filled in.
2. `conf.py` edited to add the parent folder to `sys.path`, enable the
   `sphinx.ext.autodoc`, `sphinx.ext.viewcode` and `sphinx.ext.napoleon`
   extensions, and use the `sphinx_rtd_theme` theme.
3. `sphinx-apidoc -o docs .` run from the project folder to generate the `.rst` files.
4. `modules` added to the toctree in `index.rst`.
5. `make html` run inside `docs/`.

To rebuild after changing the code:

```bash
cd docs
make clean
make html
```

Open `docs/_build/html/index.html` in a browser to view the documentation.
